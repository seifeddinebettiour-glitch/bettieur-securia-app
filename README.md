# BETTIOUR SECURIA — App

PWA (Progressive Web App) pronta per GitHub Pages.

## Funzioni
- Home app mobile
- Servizi
- Richiesta preventivo con Formspree
- Telefono e WhatsApp
- Installazione come app su dispositivi compatibili
- Service Worker per esperienza offline/cache
- Design responsive

## Pubblicazione
Carica tutti i file direttamente nel repository GitHub:
- index.html
- style.css
- app.js
- manifest.json
- sw.js
- icon.svg
- README.md

Poi attiva GitHub Pages da Settings → Pages → Deploy from a branch → main → / (root).

Per l'installazione come app è necessario aprire il sito tramite HTTPS (GitHub Pages lo fornisce).

Nota: questa versione è un'app aziendale/vetrina. Non controlla direttamente impianti d'allarme o telecamere reali. Per quello serve un'integrazione con l'hardware/software del sistema di sicurezza.
